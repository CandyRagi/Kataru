Kataru

A modern audiobook player for Android.

Download APK

v1.0.0 • Android 8.0+

Core Features

  • Plays local audiobooks (MP3, M4B, M4A, FLAC)
  • Automatic progress saving
  • Clean, modern interface

Smart Library

  • Auto-scans folders & subfolders
  • Automatic cover art detection
  • Grid or list view
  • Advanced search

Playback

  • Variable playback speed (0.5x - 2x)
  • Customizable seek intervals
  • Mini player support
  • In-app volume control
