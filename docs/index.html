Kataru

A slick audiobook player for Android.

Download APK

The Basics

  • Plays local audiobooks (MP3, M4B, M4A, FLAC)
  • Remembers your spot, every time
  • Premium, modern design

Smart Library

  • Auto-scans folders & subfolders
  • Automatic cover art detection
  • Grid or list view
  • Powerful search

Pro Player

  • Variable playback speed (0.5x - 2x)
  • Smart rewind/fast-forward
  • Mini player for multitasking
  • In-app volume control

Customization

  • Material You & Custom Colors
  • True Dark Mode
  • Glassmorphic UI
  • Home screen widget
